# 写作规范与解释

本技能适用于泛控制类研究文章，包括控制、自动化、系统建模与估计、优化决策、学习控制及相关交叉应用。具体写作规则已在技能入口与对应参考文件中完整定义，可以直接执行。

初始写作规范的完整备份在 [source-original.txt](source-original.txt)，用于核对条款来源，无须访问外部文件。下表行号按该备份计算；备份 SHA-256：`8af414758d6e36fb31c00135ca3b35b3d8e025b5958856b0de5fd258856e303d`。证据追踪、检查脚本与接续机制用于落实写作要求，不代表已经取得研究结果。备份保留原始内容，当前执行以技能正文中的规范及用户明确要求为准。

使用者后续已明确将最低引用数量从 30 篇调整为 40 篇，并要求每轮引用整理完成后提问，由使用者检查是否足够、决定是否继续第二轮或后续轮次。当前按这一要求执行；原始备份保留历史内容，不作为继续执行 30 篇标准的依据。

## 歧义与适用条件的处理

| 规范备份位置 | 问题及影响 | 本技能处理 |
| --- | --- | --- |
| 9 | `3+X` 从对象、场景、方法中选一个创新主线，主推方法创新 | 优先评估方法的真实改进，尊重使用者已指定的创新维度；不要求三个维度同时创新，不解释为贡献数量或附加章节 |
| 4–5 | “没有多少人研究”“新方法”没有检索或比较依据，易写成过度创新 | 研究缺口和新颖性需核验；按用户明确的择一创新规则，对象或场景创新允许采用已有方法，不强加方法创新 |
| 10、22 | 场景论与方法论需要明确选择 | agent 先询问，由使用者选择；已有本稿明确选择时复用。叙述方式与创新维度分别记录，未答复时不默认、不代选 |
| 14–17 | 英文时态机械统一会改变事实时间；中文没有相同语法转换 | 保留默认时态分配，依据语义标明例外；中文按完成/现在/未来表达 |
| 19、31、40、45 | 页数缺少刊名、模板与计页规则 | 保留 1.5–2 页目标与一般 3 页上限；正式排版才验证实际页数 |
| 27 | “问什么难”应是“为什么难”的笔误 | 按后者理解，保留规范备份内容 |
| 28 | 算法不自动形成理论贡献，3–5 点可能超出真实成果 | 各点绑定独立问题与证据；不足报告，不拆句凑数 |
| 33、35 | 未给真实系统、非线性特征或场景数量 n | 使用实际材料；不足保留待补，不能伪造模型、非线性或场景 |
| 41 | “自说自话”口语化且易误解为无依据陈述 | 按独立清晰解释方法处理，仍须引用来源与证明 |
| 41–42、46 | 固定两个方法模块可能与只有一个方法的研究不匹配 | 检查真实模块划分；无法合理对应时指出结构差异，不能虚构模块 |
| 43 | 要求证明至少一种性质，但没有假设和推导 | 保留为完成条件；先写证明义务，数值实验不能替代证明 |
| 51 | 固定硬件内容可能与只有仿真的研究不符 | 如实标仿真并指出硬件信息缺口；不宣称实机实验 |
| 53 | 最明显数据可能诱导选最佳样本 | 选择与核心贡献对应、比较公平且有代表性的结果，并复算 |
| 58 | “看老师怎么写”未提供导师示例 | 有示例才参照；不编造导师偏好，不阻碍按现有规则写作 |

## 指定作者引用的硬性要求

用户指定的作者必须引用。主动检索其成果，建立真实的问题、场景、方法或理论联系，在正文引用，逐位核对覆盖情况；尚未落实的作者保留为必需补齐项，不能自行省略。具体规则见 [literature-format.md](literature-format.md) 的“指定作者：必须引用”。指定作者引用与默认自引 6–7 篇要求分别核对。

未决事项不能视为已获用户确认。完成检查区分：已满足、工作稿待补、规范可选、不适用/与官方要求冲突且已说明。用户明确授权的调整记录到项目台账；所有未经调整且未满足的要求继续保留为缺口。
